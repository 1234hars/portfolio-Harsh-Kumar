Basecamp — About Me

Where the journey begins

I'm Harsh Kumar, a Master of Computer Applications graduate from Ranchi, Jharkhand, who moves comfortably between two terrains: building responsive web applications and digging through data to find what's actually true in it. My internships have run the gamut from CRM data verification across Zoho, HubSpot and Salesforce to full-stack projects built with HTML5, CSS3, JavaScript, Bootstrap, PHP and MySQL. I like structured problems, clean documentation, and shipping things that work the way they're supposed to.

Outside of formal roles, I keep exploring — an astrology consultancy platform, an EdTech career tool with an AI resume builder, an e-rickshaw booking system with live seat tracking. Each one's a different expedition.
